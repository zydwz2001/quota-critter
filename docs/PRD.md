## 1. 产品摘要

Quota Critter 是一款轻量、常驻系统托盘的 Codex 额度提示工具。它以原创像素角色 Lumo 表达额度状态，展示当前额度窗口的剩余百分比、重置时间、多个额度窗口和数据新鲜度。

应用独立于 Codex 桌面端和 VS Code 运行。用户在任一 Codex 界面产生的账户级用量，都由 Quota Critter 通过 Codex App Server 重新查询并展示。

> 产品风险声明：Codex 官方文档当前仍将 `app-server` 命令标记为实验性集成面。Quota Critter v0.1 应定位为开源实验性工具，固定并随包发布经过验证的 Codex 版本，不宣称得到 OpenAI 官方支持。

## 2. 背景与目标

Codex 用户经常同时使用桌面端和 VS Code 扩展，但额度信息被分散在不同界面中。Quota Critter 的核心价值不是“另一个宠物”，而是“跨工作界面的额度状态层”；Lumo 是信息表达和品牌识别方式。Codex 桌面端已有浮动 Pets，但 IDE 扩展没有浮动宠物层。[Codex Pets](https://learn.chatgpt.com/docs/pets)

### v0.1 目标

1. 用户安装后 2 分钟内看到真实 Codex 额度。
2. 同时适配 Codex 桌面端与 VS Code Codex 扩展的使用场景。
3. 额度百分比、窗口时长、重置时间不依赖硬编码。
4. 默认低打扰：可拖动、收起、隐藏、关闭动画。
5. 不建设自有后端，不上传认证信息，不默认收集遥测。
6. 形成可截图传播的原创视觉资产 Lumo。

### 非目标

- 不替代 Codex 桌面端任务状态宠物；
- 不读取或展示 Codex 对话内容；
- 不展示 API Key 的 Platform 账单与组织成本；
- 不修改额度、购买 Credits 或自动消费重置权益；
- v0.1 不支持 Linux、移动端、多账户和主题商店；
- 不自动修改用户的 `config.toml`。

## 4. 功能需求

### P0

#### FR-001 首次启动与认证

- 启动本地 Codex App Server；
- 查询当前账户状态；
- 有 ChatGPT 登录时直接读取额度；
- 无登录时提供官方 ChatGPT 登录按钮；
- 前端不接触访问令牌；
- API Key-only/Bedrock 模式显示“当前版本只支持 ChatGPT Codex 额度”。

#### FR-002 额度读取

- 读取 `account/rateLimits/read`；
- 优先读取 `individualLimit` 的真实账户使用量，兼容 `rateLimitsByLimitId` 与单桶 `rateLimits`；
- 没有 `individualLimit` 时再展示 `primary` 与 `secondary` 时间窗；
- 使用 `windowDurationMins` 生成窗口标签；
- 使用 `resetsAt` 计算倒计时；
- 服务未返回的可选字段不得导致崩溃。

#### FR-003 悬浮视图

- 默认只显示 Lumo 和斜向半弧额度轨道，不显示数字；
- 无系统边框、可拖动、可置顶；
- 点击 Lumo 打开/关闭详情；
- 详情中显示主额度百分比、进度条、重置时间和同步状态。

#### FR-004 详情面板

- 展示所有额度桶和窗口；
- 每行显示窗口标签、剩余百分比、重置时间；
- 显示套餐类型（服务返回时）；
- 显示最后同步时间；
- 手动刷新放在系统托盘菜单。

#### FR-005 托盘与持久化

- 托盘单击显示/隐藏；
- 菜单支持显示/隐藏、锁定位置、置顶、开机启动、刷新、设置、退出；
- 保存位置、显示器、展开状态、动画设置和刷新间隔；
- 退出时终止由应用启动的 sidecar。

#### FR-006 异常状态

支持 Codex runtime 未找到、sidecar 启动失败、未登录、不支持认证模式、网络离线、超时、协议不兼容、额度为空。每种错误都要给出下一步动作，不展示堆栈。

#### FR-007 无障碍

- 颜色不是唯一状态信号；
- 支持键盘访问；
- 遵循系统 reduced motion；
- 关键文字满足 WCAG AA 对比度。

### P1

- 使用 `account/usage/read` 显示 Token 活跃度；
- 重置庆祝动画；
- 全局快捷键；
- 自动更新；
- 日志导出和诊断复制；
- 中英文切换。

### P2

- 多主题和用户 Sprite；
- `notify` 回合完成联动；
- Linux；

## 5. 核心流程

### 首次启动

```text
启动应用 -> 创建托盘 -> 启动 App Server -> initialize/initialized
        -> account/read -> 已登录则读取额度
        -> 未登录则打开官方登录 -> 登录完成后再次读取额度
```

### 日常启动

1. 恢复位置并显示最后缓存，标记“同步中”。
2. 成功读取后替换缓存并更新时间。
3. 读取失败则保留缓存，显示“上次同步于 …”。

### 收起/展开

- 单击 Lumo 打开或关闭详情；
- 默认态不显示百分比、进度条和时间，只使用轨道节点表达额度；
- 托盘控制整体显示/隐藏；
- 锁定后不响应拖动。

## 6. 额度展示

App Server 返回 `usedPercent`，界面显示：

```text
remainingPercent = clamp(round(100 - usedPercent), 0, 100)
```

永远使用“剩余 / left”文案，不显示无语义百分比。

| 剩余比例 | 状态 | 表现 |
| --- | --- | --- |
| 80–100% | Full | 上浮、卫星点闪烁 |
| 20–79% | Steady | 轻微呼吸 |
| 1–19% | Low | 下沉、珊瑚色脉冲 |
| 0% | Exhausted | 静止、显示下一次重置 |
| 刚重置 | Reset | 一次性环绕动画 |
| 数据过期 | Stale | 降低饱和度、显示同步时间 |
| 无数据 | Unknown | 占位与明确错误文字 |

仅倒计时归零不能判定服务已重置，必须等待新数据确认。

## 7. 非功能要求

验收目标：

- 显示缓存 UI 冷启动小于 1.5 秒；
- 正常网络下首次真实额度小于 4 秒；
- 空闲主进程内存目标小于 60 MB，不含 Codex sidecar；
- 空闲 CPU 平均低于 1%；
- Sprite 与静态资源目标小于 1 MB；
- 适配 macOS Apple Silicon 与 Windows 10/11 x64；
- 支持 DPI 100%–200%、多显示器和睡眠唤醒。

安全与隐私：

- 无自建后端；
- 不读取会话正文；
- 不在前端接触 Token；
- App Server 使用本地 stdio，不开放监听端口；
- 日志脱敏邮箱、Token、账户 ID 和完整路径；
- 诊断包必须由用户主动触发。

## 8. v0.1 验收标准

1. macOS 和 Windows 可安装并打开。
2. ChatGPT Codex 用户可复用登录或完成登录。
3. 额度与重置时间语义正确，支持主/次窗口。
4. VS Code 工作时挂件仍能置顶、拖动、刷新。
5. 断网保留最后数据并明确标记过期。
6. 恢复网络后自动重连。
7. 退出后没有遗留 sidecar。
8. reduced motion 下没有循环动画。
9. 不上传或展示 Codex 会话内容。

- Beta：固定版本 sidecar、macOS Apple Silicon、Windows x64、GitHub Release；
